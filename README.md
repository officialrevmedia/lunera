# lunerasmart.com

Static site for Lunera Smart Technologies, hosted on GitHub Pages.

## Files
- `index.html` coming-soon home page (launch December 1, 2026)
- `privacy.html` privacy policy
- `404.html` custom not-found page (GitHub Pages serves it automatically)
- `assets/` WebP images, Open Graph image, favicon set
- `sitemap.xml`, `robots.txt`, `site.webmanifest`, `CNAME`, `.nojekyll`

## Before going live
1. In `index.html`, `privacy.html` and `404.html`, replace `YOUR_GOOGLE_VERIFICATION_CODE_HERE` with the code from Google Search Console (only needed if you verify with the meta tag; DNS or the HTML file method also work).
2. In the same three files, replace `G-XXXXXXXXXX` with your Google Analytics 4 measurement ID. Analytics stays off until a real ID is present.
3. Optionally replace `YOUR_BING_VERIFICATION_CODE_HERE` for Bing Webmaster Tools.
4. Commit and push. GitHub Pages publishes within a minute or two.

See the Launch Setup Guide PDF for step-by-step Search Console and Analytics instructions.
