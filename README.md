# lunerasmart.com

Coming-soon site for Lunera Smart Technologies, hosted on GitHub Pages. Launch date: December 1, 2026.

## Files
- `index.html` home page: animated dot hero, scroll sections, countdown, contact form
- `privacy.html` privacy policy, `404.html` custom not-found page
- `assets/` self-hosted fonts (Geist, Geist Mono), photos (WebP), favicons, Open Graph image
- `sitemap.xml`, `robots.txt`, `site.webmanifest`, `CNAME`, `.nojekyll`, `favicon.ico`

## Contact form
The form sends every submission to info@lunerasmart.com through FormSubmit (formsubmit.co). No account is needed.
**One-time step:** the first time someone submits the form on the live site, FormSubmit emails info@lunerasmart.com an
"Activate Form" link. Click it once; every message after that is delivered straight to the inbox.
Send yourself a test message right after publishing to trigger this.
If the service is ever unreachable, the form falls back to opening the visitor's email app addressed to info@lunerasmart.com.

## Before going live
1. Replace `YOUR_GOOGLE_VERIFICATION_CODE_HERE` in the three HTML files with your Search Console HTML-tag code (only if you verify by meta tag).
2. Replace `G-XXXXXXXXXX` in the three HTML files with your GA4 Measurement ID. Analytics stays off until a real ID is in place.
3. Optional: replace `YOUR_BING_VERIFICATION_CODE_HERE`.
